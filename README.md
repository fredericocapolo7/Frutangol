
# Frutangol | Gestão de Frutas

O **Frutangol** é uma aplicação web minimalista desenvolvida para o controlo, registo e gestão de frutas. O sistema permite cadastrar novas frutas com detalhes específicos, pesquisar na base de dados de forma dinâmica e gerir os registos existentes.

## 🚀 Funcionalidades
- **Cadastro Completo:** Registo de frutas com Nome, Cor, Sabor e Origem.
- **Pesquisa Dinâmica:** Barra de busca em tempo real para encontrar itens facilmente.
- **Tabela de Gestão:** Visualização organizada de todos os registos com opções de exclusão.
- **Interface Limpa:** Design responsivo e focado na facilidade de uso.

## 🛠️ Tecnologias Utilizadas
- HTML5
- Tailwind CSS / CSS
- JavaScript


# Frutangol | Fruit Management

**Frutangol** is a minimalist web application designed for tracking, registering, and managing fruit inventory. The system allows users to easily add new fruits with specific attributes, search the database dynamically, and manage existing records.

## 🚀 Features
- **Complete Registration:** Add fruits with Name, Color, Taste, and Origin.
- **Dynamic Search:** Real-time search bar to find items instantly.
- **Management Table:** Organized table view of all records with deletion options.
- **Clean Interface:** Responsive design focused on usability.

## 🛠️ Built With
- HTML5
- Tailwind CSS / CSS
- JavaScript
